# Soft Enterprise V2 Design System
## Inspiration boundaries
Inspired by familiar ChatGPT (calm navigation), ClickUp (module organization/views), and Apple (clarity and restrained interaction). These are UAB-created design choices, **not** internal/proprietary vendor tokens. Preserve existing brands/frameworks where supplied.

## UX principles
- Clean, neat, compact, readable, interactive and minimal; functional information over decoration.
- Flat surfaces and subtle separators; no excessive boxes, pills, decorative gradients, or floating shadows.
- One strong primary action per work area; secondary actions compact and discoverable.
- Stable iconography: Lucide 16px default; always pair essential icon-only actions with accessible names and tooltips.
- Dense layouts must not sacrifice keyboard access, 200% text zoom, focus visibility or touch minimums.

## Page header, top bar & view toolbar (project rules)
- **No breadcrumb row** anywhere above the page title.
- **Page title lives in the top bar** (left side, 18px semibold, ellipsis when long) — not in the page body. Pages with extra page-level actions show them as a slim right-aligned row; list pages put actions in the view toolbar.
- **Description in an info icon:** never shown as visible text; ⓘ (16px, muted) right after the title opens a dark tooltip (dark surface, white 13px text, ~8px radius, arrow pointing up, max ~340px wide) on hover, keyboard focus and tap; Esc dismisses; linked with `aria-describedby`; the icon has an accessible name (e.g. "About Appointments").
- **Top bar = 3 zones:** left = title + ⓘ (plus menu button on tablet/phone); **centre = global search** (Ctrl/⌘+K, up to ~440px wide); right = workspace switcher (compact; icon-only on phones), notification bell, account.
- **Two-line view toolbar (list pages):** line 1 `.view-toolbar.view-tabs-row` = `[view tabs (scroll)][+][Unsaved ▾] ⟷ [Export][Quick add][Primary add]`, min-height 44px, bleeds to the page edges (`margin: 0 -16px 10px; padding: 0 16px`) with `border-bottom: 1px solid var(--s-border)`; tabs stretch to the row height and the active tab's 2px underline sits at `bottom: 0` on that line; no vertical divider on this line. Line 2 `.view-tools.view-tools-row` = `[search ~220px] [Filters ⌄] [Columns ⌄]` left-aligned, 8px below. **Sliding underline:** one `.view-tab-ink` span (absolute, bottom 0, 2px, accent, radius 2px) inside the `position: relative` tab list, placed from the active tab's `offsetLeft`/`offsetWidth` (inset 4px each side) via `transform: translateX()` + `width`, `transition: transform 220ms, width 220ms` (none under `prefers-reduced-motion`); re-measured with a ResizeObserver; tab colour/opacity changes transition 160ms. Then the chips/bulk line, then the table.
- **View overflow:** views start at the left; the **"+"** add-view button (plus icon only, 32px square, borderless/transparent, hover = hover fill, tooltip + aria-label "Add view") follows the last view, then a flexible gap, then a 1px vertical divider (22px tall) before the tools. When views grow, the button moves right until it meets the divider and stops; extra views slide under it (horizontal scroll, hidden scrollbar) and fade softly into the page background on the hidden side(s) — a ~40px light gradient fade (transparent → canvas colour) with at most a faint shadow, never a dark shadow; keep the active tab scrolled into view.
- **Compact spacing:** page content padding ≈8–12px top/bottom and 16px left/right; toolbar-to-table gap ≈10px.
- **Uniform control height everywhere:** buttons are sized by ONE shared component token (`--c-control-h-compact` = 32px; 44px on coarse/touch pointers). Every page — list toolbars, calendar toolbar, dialogs, footers, admin — uses it; never set button heights per page or per toolbar.
- **Underline view tabs:** each view = 32px tall, no border, transparent background, view-type icon (14px) + name, secondary text colour (hover → text colour), 12px gap between tabs. Selected view: text colour, semibold, `::after` 2px accent underline (radius 2px, inset 4px each side) at the bottom of the tab row. ⋮ (more-vertical) menu 22px, `opacity: 0` except on tab hover, `:focus-within` and the active tab (0.6).
- **Uniform view tabs:** user-created views render exactly like built-in views; no lock/team/scope icon on the tab — scope is shown in the tab tooltip and the sidebar.
- **Filter button:** label is just "Filter" (no count); active filters are indicated by the accent/active button style and the filter chips row.
- No filter-chip row (the "All of" line is commented out in code); active filters = accent dot on "Filters" + the Filters panel.
- **Table look:** compact rows (34px); header labels 12px muted with faint (40%) sort arrows on every sortable column; no column separators (resize handle shows on header hover); status/master cells = coloured dot + coloured text, no pill background; relation cells plain text (accent + underline on hover); sticky right column titled "Actions" with view/edit/more icons.
- **Frozen pagination footer:** table + footer form one bordered panel that fills the remaining page height; rows scroll inside; footer (44px, top border): left `1–25 of N items`; right numbered pages with ellipsis (‹ 1 2 … N ›) followed by the custom `25 / page` dropdown (SelectMenu; options 25/50/100; selected = accent tint + ✓; opens upward).
- **Table header labels:** regular weight (400), supportive size, muted colour.
- **Sticky Actions column shadow:** when the table overflows horizontally and is not scrolled fully right, the sticky right Actions column gets a soft left-edge shadow (`-10px 0 12px -8px rgba(20,20,30,.16)` plus the 1px divider). Recompute on scroll and resize; when everything fits or the end is reached, show only the 1px divider.
- **SelectMenu (custom dropdown) — the only dropdown allowed:** trigger = 1px strong border, 7px radius, value + chevron (up when open), muted placeholder, red border when invalid, disabled fill; full-width (`block`) in forms at 40px, compact 32px in toolbars/tables/footers/filter rows/panels. Popover: options 32px, hover tint, selected accent tint + check, max-height 260px scroll, search box above the list when > 8 options, "No matches" empty state; keyboard ↑/↓/Enter/Esc and type-to-jump. Popover z-index above dialogs. No native `<select>` anywhere.
- **Anchored toolbar panels:** Columns, Filter and the view form ("+ Add view", Rename, Duplicate, Save as new) are popovers anchored under their trigger (≈320–340px wide), with a header, content and a right-aligned footer (Cancel / primary). No modal scrim.
- **Popover placement:** popovers re-measure and re-place whenever their own size changes (ResizeObserver) as well as on scroll/resize, so a panel that grows (e.g. quick → advanced filters) never runs off-screen.
- **Panel triggers:** toolbar buttons that open a panel (Filters, Columns) carry a trailing chevron (⌄ closed, ⌃ open).
- **Toolbar button states:** `.is-open` (hover-grey fill, solid strong border) only while its panel is open. Active filters = 6px accent dot after the "Filter" label (accessible name "Filter, N active").
- **Segmented control:** `width: fit-content` — the track hugs its options; never stretched to the container width.
- **Sidebar toggle:** panel icon in the context-sidebar header (top-right) collapses the sidebar; when collapsed the same icon sits at the top-left of the top bar to expand. Never at the bottom.
- **Global tooltip (TooltipLayer):** one portal-based layer at the app root; elements opt in with `data-tooltip` (+ optional `data-tooltip-placement`). Bubble: dark (`gray-800`, lighter grey in dark mode), white supportive-size text, 6px 10px padding, ~7px radius, small shadow, 6px arrow tracking the trigger centre; placement top → flips bottom; clamped 8px from viewport edges; rail tooltips to the right. 350ms hover delay; instant on keyboard focus; dismiss on mouse leave, scroll, mousedown, blur and Esc. No CSS `::after` tooltips and no native `title` on page elements.
- **Auto tooltip for truncation:** the tooltip layer checks the hovered element and up to 3 ancestors; if one is truncated (`text-overflow: ellipsis` overflowing, or a line clamp overflowing) it shows that element's full text. Truncation beats any `data-tooltip` hint.
- **DateText:** cells always show the date only, "16 Oct, 2026" (non-padded day, short English month, comma, year), even for date-time values; tabular numbers, no wrap. Tooltip shows the full value "Fri, 16 Oct 2026 08:30 AM" (2-digit 12-hour time + AM/PM when a time exists). Calendar headers use "Fri, 16 Oct"; time-only labels (schedules) use "08:30 AM".
- **EmptyValue:** italic "N/A" only (no icon), `--c-empty-value-fg: color-mix(in srgb, var(--s-text) 22%, var(--s-panel))` (very light), supportive size; accessible name "Not available". Replaces every "—"/blank placeholder.
- **Borderless table:** `.content-surface.is-table { border: 0 }` (white surface + radius only), no vertical body-cell lines; header cells keep a short divider (`.col-resize` `border-right: 1px solid var(--s-border)`, inset 9px; strong on hover, accent while dragging; transparent on the last data column), the Actions column keeps its 1px left divider (`box-shadow: -1px 0 0 var(--s-border)`) and adds the soft scroll shadow (`-1px 0 0 var(--s-border), -10px 0 12px -8px rgba(20,20,30,.16)`) while columns are under it. Horizontal row lines (1px `--s-border`) stay; the header row is white with one bottom line.
- **No accent indicator lines:** no `::before` bar beside the active rail icon, no `border-left` on calendar events (padding 3px 8px; overlap = `outline: 1px dashed var(--tone-fg); outline-offset: -1px`), no inset accent shadow on the active table row (row tint only).
- **Sort indicator:** arrow always after the label (right side) for every column. Idle arrows faint (40%); active arrow accent colour.
- **Sorted column:** no tint — the header label and its sort arrow switch to the text colour (other arrows stay faint).
- **Actions column:** sticky right, `text-align: center` for title and icons, width = icons × 30px + gaps (2px) + 16px padding (3 icons → 110px); never grows.
- **Column width distribution:** configured column widths are minimums. Measure the table panel width (ResizeObserver); if the data columns + checkbox + Actions are narrower, scale every data column by the same factor so the table exactly fills the panel (last data column takes the rounding remainder). If wider, keep minimum widths and scroll horizontally. Resizing edits the configured (minimum) width.
- **Header/value alignment:** ALL table columns are left-aligned (including numbers, money, durations and dates); values start exactly under the header label (same 10px padding). Hover-only cell controls (inline-edit ✎) are absolutely positioned overlays (22px, vertically centred, 4px from the right edge) and take no layout space.
- **Tooltip lookup order:** walk outwards from the hovered element (up to 4 levels); the nearest source wins; on the same element, truncated full text beats a `data-tooltip` hint. List tooltips use `data-tooltip` (newline-separated items) + `data-tooltip-title` (heading).
- **List tooltip:** dark bubble, 8px 12px padding, min-width 140px; heading = supportive size, semibold, uppercase, 0.06em letter-spacing, 65% white; items = one per line, 2px gap.
- **No duplicate info:** content shown in a tooltip is not also rendered as visible text (menus: disabled reason only in tooltip + sr-only).
- **Expanded row card:** `position: sticky; left: 56px` (the expanded row's cell must have `overflow: visible`, otherwise the cell becomes the sticky container and the card scrolls away), width = visible table width − 56px − Actions width − 12px (ends just before Actions), does not move during horizontal scroll, light fill (~2.5% text over panel), 1px border, 10px radius, 4px 12px padding; inner table headings regular weight + muted, rows separated by 1px lines, values left-aligned.

Inside: only `.detail-items-table` (the `.detail-items-head` title line is commented out; caption sr-only) — columns `# · Service · Description · Qty · Unit price · Amount`, `#` 40px secondary colour, th 400 muted with 1px bottom border, td 7–8px vertical padding + 1px row line, `tfoot` total (label right, value semibold) when > 1 item. ## Behavior
- Progressive disclosure, calm hover states, contextual actions, keyboard shortcuts, predictable scroll.
- Responsive: desktop full shell; tablet collapses secondary nav; phone uses drawer/bottom-safe controls with deliberate table fallback.
- Preserve unsaved forms across inspector/tab navigation. Confirm destructive actions, restore focus after dialogs, honor reduced motion and forced colors.
